# Google Design & Material Color Utilities Mirror (`google-design`)

Mirrors [Google Design](https://design.google/) articles on Material 3 Expressive, research behind Expressive UX, adaptive/large-screen design, typography, motion, color, accessibility, and UX writing, alongside official `material-foundation/material-color-utilities` HCT & ColorSpec2021/2025/2026 concept guides and Kotlin specs.

## Usage

```bash
uv run python sources/google-design/refresh.py --no-assets --workers 10 --verify
uv run python sources/google-design/refresh.py --check
uv run python sources/google-design/refresh.py --verify
```
